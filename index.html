    Math Expression Solver

    JavaScriptParserEducation

    A web app that parses and solves algebraic expressions step-by-step, showing each transformation along the way.

    What it does

    You type in an algebraic expression, and the solver breaks it down into a sequence of equivalent forms — combining like terms, distributing, isolating variables — so you can see why the answer is what it is, not just what the answer is.

    How it works

    • Tokenizer turns the raw string into a stream of tokens (numbers, operators, variables).
    • A recursive-descent parser builds an abstract syntax tree.
    • Rewrite rules apply one transformation at a time, producing a step list.
    • Each step is rendered with a short plain-English explanation.

    What I learned

    • How to design a small expression grammar and keep it readable.
    • Why operator precedence and associativity are worth getting right the first time.
    • That showing work is genuinely harder than producing the answer.

    Anesthesia Dose Calculator

    PythonFlaskHealth

    A clinical decision-support tool that calculates weight-based drug dosages for common anesthetics, with safety checks and clear unit handling.

    What it does

    Enter a patient's weight and the drug you're working with, and the tool returns the recommended dose range in the right units. It flags values outside safe ranges, warns about common unit mix-ups (mg vs. mcg), and shows the underlying calculation so nothing is a black box.

    How it works

    • Drug library stored as structured data (name, unit, mg/kg range, notes).
    • Flask backend handles the dose math and validation.
    • Frontend is a small form that highlights warnings inline.
    • Every result includes the formula used and a citation to the source range.

    What I learned

    • Unit handling is where most bugs live — always be explicit about mg vs. mcg.
    • Safety-critical tools should show their work, not just their answer.
    • Designing for a clinician's workflow means fewer clicks, bigger text.

    Flight Plan Visualizer

    ReactMapboxAPI

    Upload a flight plan and see it plotted on an interactive map with altitude profiles and rough fuel estimates.

    What it does

    Drop in a flight plan file, and the tool draws the route on a map, shows the planned altitudes along the way, and estimates fuel burn using a simplified model. It's a learning tool for people who want to see how the numbers relate to the picture.

    How it works

    • Parser reads the plan and extracts waypoints, altitudes, and speeds.
    • Mapbox renders the route and lets you scrub along it.
    • Altitude profile drawn below the map using SVG.
    • Fuel estimate uses a basic burn rate scaled by phase of flight.

    What I learned

    • Flight plan formats are surprisingly fiddly — real-world data is messy.
    • Coordinating a map and a chart is all about keeping one source of truth.
    • Any estimate is only as good as the assumptions behind it.

    Raccoon Tracker

    Raspberry PiPythonIoT

    A playful IoT dashboard that logs "raccoon visits" to a backyard feeder using a motion sensor and a Raspberry Pi.

    What it does

    A motion sensor watches the feeder. When something moves, the Pi takes a timestamped snapshot, logs it, and pushes the event to a small web dashboard. Over time you get a nice chart of when the raccoons are most active — which, as it turns out, is basically all night.

    How it works

    • PIR sensor on a GPIO pin triggers the capture script.
    • Python script grabs a still from the camera and writes a log entry.
    • Flask app serves a dashboard with a chart and a recent-events list.
    • Runs headless on the Pi and survives reboots.

    What I learned

    • Debouncing sensors is half the battle with physical inputs.
    • Long-running scripts need care — logging and restarts matter.
    • Raccoons are, without question, the most dedicated visitors.

    Cheese Recommender

    Pythonscikit-learnML

    A small ML model that suggests cheeses based on your flavour preferences, trained on a hand-curated dataset of 300+ varieties.

    What it does

    Rate a handful of cheeses you already know, and the model recommends a few new ones to try — leaning toward styles it thinks match your taste. It's a fun excuse to build a recommender from scratch on a small, opinionated dataset.

    How it works

    • Dataset: name, style, milk, ageing, and a few flavour axes (sharp, creamy, funky, salty, nutty).
    • User ratings become a preference vector, and cosine similarity picks the nearest cheeses.
    • Simple content-based filtering — no collaborative data needed.

    What I learned

    • Small, clean datasets often beat big, messy ones for a side project.
    • Feature design is the real model — the algorithm is almost an afterthought.
    • People will absolutely argue with a cheese recommendation. That's the fun part.

    Periodic Table Explorer

    VueData VizEducation

    An interactive periodic table with detailed element data, electron configurations, and a quiz mode.

    What it does

    A full periodic table you can click around in. Each element shows its properties, electron configuration, and a short description. There's also a quiz mode that asks you to identify elements from their properties — useful for students, and fun for anyone who likes chemistry.

    How it works

    • Element data stored as a JSON file (name, symbol, number, category, properties).
    • Vue renders the grid and handles selection and filtering.
    • Colour coding by category with a legend and toggle.
    • Quiz mode pulls random elements and asks property-based questions.

    What I learned

    • Layout grids are the easy part — the data model is the real work.
    • Good colour choices make a data viz useful, not just pretty.
    • Quizzing yourself is still the fastest way to learn something.
